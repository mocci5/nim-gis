# NiM-GIS

Complement de QGIS basat en [qgis-mcp](https://github.com/nkarasiak/qgis-mcp) de Nicolas Karasiak, que connecta QGIS amb assistents d'IA mitjançant MCP.

NiM-GIS l'amplia amb una base de dades PostgreSQL/PostGIS amb informació agronòmica, hidràulica i ambiental de Catalunya. Juntament amb un segur de eines predeterminades per estudiar el projecte objecte. 

Amb aquesta fusió aconseguim automatitza l’estudi i la digitalització de projectes. 

## Llicència
